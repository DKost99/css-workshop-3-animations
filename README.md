# 🎬 Воркшоп 2. Практика CSS-анимаций

Учебный проект для курса **«Современный CSS для frontend»** (Модуль «Основы движения»).

Перед вами **статичный макет**: четыре белые карточки с подписями «Плавное появление», «Мигание», «Пульсация», «Движение». Сейчас они ничего не делают. Ваша задача — **шаг за шагом оживить каждую** через `@keyframes`, превратив статику в динамику.

Подписи на карточках — это ваше техническое задание: каждая говорит, какую анимацию нужно реализовать.

---

## 🎯 Что вы отработаете

- описание сценариев анимации через `@keyframes` (от простого `from`/`to` до многокадрового);
- запуск анимаций свойством `animation` (длительность, `timing-function`, `infinite`, `alternate`);
- разные приёмы: изменение `opacity`, `transform: scale`, `translateX`, `translateY`;
- заботу о доступности через `prefers-reduced-motion`.

## 📋 Задание по этапам

Идём от простого к сложному — не в порядке карточек, а по нарастанию сложности. Каждый этап: описать `@keyframes`, затем подключить его к нужной карточке.

Общий шаблон подключения (у всех карточек анимация зациклена и идёт туда-обратно):
```css
.box-N {
  animation: name duration timing-function iteration-count direction;
}
```

### Этап 1 — Мигание (карточка `.box-2`)
Самая простая анимация: карточка плавно то исчезает, то появляется.
- опишите `@keyframes blink` — от `opacity: 0` к `opacity: 1`;
- подключите к `.box-2` с длительностью ~0.4s.

### Этап 2 — Пульсация (карточка `.box-3`)
Карточка слегка «дышит», увеличиваясь и уменьшаясь.
- опишите `@keyframes pulse` — от `scale(1)` к `scale(1.05)`;
- подключите к `.box-3` с длительностью ~0.4s. Обратите внимание: `alternate` здесь делает пульсацию плавной, без рывка.

### Этап 3 — Движение (карточка `.box-4`)
Карточка ездит из стороны в сторону.
- опишите `@keyframes slide` — от `translateX(0)` к `translateX(30px)`;
- подключите к `.box-4` с длительностью ~1s.

### Этап 4 — Плавное появление (карточка `.box-1`)
Самая интересная: карточка «выплывает» снизу, проявляясь. Здесь нужен **многокадровый** сценарий.
- опишите `@keyframes fade-in`: в начале — сдвиг вниз (`translateY(50px)`) и `opacity: 0`; в конце — на месте (`translateY(0)`) и `opacity: 1`;
- добавьте промежуточный кадр `35% { opacity: 0; }`, чтобы карточка оставалась невидимой первую треть анимации, а потом мягко проявлялась;
- подключите к `.box-1` с длительностью ~0.9s.

### Этап 5 — Доступность (для всех карточек)
Движение вредит части пользователей. Уважим системную настройку «уменьшить движение».
- добавьте медиазапрос `@media (prefers-reduced-motion: reduce)`, который отключает анимации у всех карточек;
- проверьте: включите в системе «уменьшить движение» и убедитесь, что карточки замерли.
